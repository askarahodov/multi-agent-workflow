# Инструкции участникам разработки Multi-Agent Workflow

Применяется к людям и агентам, изменяющим **этот репозиторий**. Не является системным промптом для агентов пользовательских проектов.

1. Прочитать [конституцию проекта](docs/governance/constitution.md), [обязательный GitFlow](AGENT_GITFLOW_RULES.md) и [карту владения](docs/architecture/OWNERSHIP.md). Машинная схема GitFlow: `gitflow-policy.schema.json`; карта проверок — §9 конституции. Проверить актуальный main, GitHub Issue, связанные PR и границы задачи.
2. Один Issue/карточка — одна цель и одна ветка. Использовать назначенную ветку и изолированный checkout; не изменять чужую ветку, не писать в main. Не расширять scope и права без согласования.
3. Перед реализацией зафиксировать требования, критерии приёмки, затронутые контракты, тесты и ограничения. Конфликт нормативных источников — блокер, а не повод выбрать удобный вариант.
4. Сохранять независимый native runtime. Инструменты разработки платформы (включая Hermes) не являются runtime-зависимостью продукта.
5. Выполнять проверки на фактическом SHA. Следовать каноническому GF-09: полный локальный make check либо разрешённое действующей версией GitFlow эквивалентное CI-покрытие с отметкой NOT_RUN; обязательный CI сохраняется. Отсутствие доступа, теста или независимого подтверждения обозначать BLOCKED/UNKNOWN. Не скрывать ошибки, не подменять live-проверки mock.
6. Запрещены публикация секретов, расширение полномочий через промпт, обход security/QA/approval, самостоятельная приёмка собственной работы. Не выполнять production-операции без отдельного разрешения.
7. Основная документация, инструкции, отчёты и критерии приёмки — на русском. Технические спецификации, машинные ключи, команды и код допускаются на английском. Поддерживать документацию в том же PR.
8. Передать результат через PR: Issue, точный SHA, изменённые требования/контракты, тесты, evidence, ограничения, rollback при необходимости. Независимое review обязательно перед merge. Для разрешённой области автоматизированного evidence review применяется только вступившая в силу политика GF-09 §4.2; самосогласование запрещено.
