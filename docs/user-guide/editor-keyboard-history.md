# Работа с графом с клавиатуры и история действий

Редактор workflow поддерживает drag-and-drop мышью и эквивалентные кнопки **«+ Добавить на схему»** у каждого типа ноды. Для создания связи без мыши выберите источник и цель в панели **«Связь от → к»** и нажмите **«Создать связь»**. Нельзя создавать связь с самой собой либо точный дубликат; остальные ошибки структуры (ветвления, циклы, неверные ссылки) показывает проверка графа, и публикация блокируется.

**«Отменить» / «Повторить»** работают по истории текущего документа (до 60 последовательных правок). Ctrl/Cmd+Z и Ctrl/Cmd+Shift+Z/Ctrl+Y действуют, когда фокус не находится в поле ввода; там сохраняется стандартное поведение редактирования текста. Открытие другого workflow, импорт и создание нового документа обнуляют историю: нельзя отменой случайно перейти через границу сохранённых документов. Исполняется только линейный граф Start → (Agent → automatic Gate)+ → End; остальные типы — безопасный черновик.

История существует лишь в текущей сессии браузера, не отменяет серверные публикации или ранее запущенные процессы. Любые изменения после публикации требуют нового сохранения и неизменяемой версии. Для полного завершения #253 остаются runtime semantics остальных нод, интеграция с настройками агента и операторская Chromium/Compose приёмка.
