# Справочник нод и стартовых схем

В **Редакторе** палитра показывает назначение каждой из 11 нод. При выборе узла правая панель объясняет **зачем**, **когда**, **вход**, **выход**, **настройки** и **пример**; Start/End не требуют особых параметров, поэтому их инспектор ограничен подписью, но не справкой.

**Три готовых черновика:** «Простой агент», «Разработка + проверка», «Семь стадий SDLC». Загрузка шаблона заменяет текущий несохранённый граф только после подтверждения. Шаблоны оставляют ID агента, модель и политику пустыми — это честные незавершённые конфигурации. Graph validation подсветит недостающие реальные ссылки. Отсутствуют автозапуск и платные вызовы.

**Важное ограничение:** визуальные шаблоны — примеры проектирования, а не исполняемые процессы. Исполнение и публикация схем из редактора остаются в #253. Текущий сервер запускает отдельные task specs из «Запуски»; нельзя считать, что нарисованный condition/parallel/join/human approval/gate/delay уже реализован в runtime. Полную связь draft → persistent published workflow → orchestration и живые тесты нужно закончить перед закрытием #253.
